# Vasko – prototype (GitHub Pages)

Denne grenen inneholder bare den klikkbare prototypen som QR-koden på brosjyrene peker til:
https://phiri-madalitso.github.io/Vasko/

- `index.html` – hele prototypen i én fil (skrifter og bilder er bakt inn): fra «Hva skal vi vaske?» til levert, med gründervideo og e-post for tilbakemelding til slutt
- `grundere-v2.mp4`, `grundere-forside.jpg` – gründervideoen og stillbildet som vises før den spilles

Grenen er adskilt fra `main`, så endringer her utløser ikke deploy til Scaleway.

Siden sender ingen data noe sted. Adresse og svar blir bare liggende i nettleseren til den som tester, og innstillingene for Plausible og Google-skjema er tomme.
